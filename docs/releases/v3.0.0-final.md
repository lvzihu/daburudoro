# DaburuDoro 3.0.0 — Choose Your Companion

Released 2026-08-06 after iterative owner testing in
[PR #2](https://github.com/lvzihu/daburudoro/pull/2).

Version 2 made DaburuDoro dependable enough for daily use. Version 3 makes the
body-double personal: choose who works beside you, change companions between
Focus blocks, and give each one private local Break music.

## Five companions, five Focus activities

- Yellow plays games.
- Blue fishes.
- Green hosts a radio show.
- Red works on a computer.
- Purple directs a movie from a production monitor.

Only one companion appears at a time. Choose before starting, or use the
five-hats control during Break to queue someone for the next Focus block. Each
animation keeps the character and furniture anchored while a working hand and
its operated prop move.

## A different kind of Break

All five companions sleep during Break with three shared rising `Z`s. Assign
one local MP3, M4A, or WAV file to each color and DaburuDoro will:

- start it automatically when that character enters Break;
- play it once without looping;
- preserve playback while the widget is hidden;
- follow Timer Pause and Resume;
- use one remembered global volume; and
- fade smoothly over the final five seconds before Focus.

Music remains in DaburuDoro's private local-data directory. It is never
uploaded, streamed, committed, or included in the release package.

## Smoother daily use

- A centered chevron gives the compact progress affordance a large click target.
- Remaining time is visualized vertically along the character's left side.
- A bare character-level `×` hides the widget without stopping the timer.
- The five-hats control opens companion, music, and volume settings.
- Character dragging and clicking no longer get stuck passing through to the
  desktop.
- Picker buttons remain stable across timer updates, so one click reliably
  changes companions.

## Build and install

The attached `DaburuDoro-3.0.0-mac-arm64.zip` contains the Apple Silicon macOS
application. Unzip it and drag `DaburuDoro.app` to Applications.

This personal development build is unsigned and unnotarized. macOS may require
Control-click → Open the first time it launches.

To build from source with Node.js 22+:

```bash
npm install
npm test
npm run build:mac
```
