# DaburuDoro 3.0.0 — Choose Your Companion

> Draft release notes. Publish after owner acceptance and merge.

Version 2 made DaburuDoro dependable enough for daily use. Version 3 makes the
body-double personal: choose who works beside you, change companions between
Focus blocks, and give each one private local Break music.

## Five companions, five Focus activities

- Yellow plays games.
- Blue fishes.
- Green hosts a radio show.
- Red works on a computer.
- Purple directs a movie from a production monitor.

Only one companion appears at a time. Choose before starting, or use the
five-hats control during Break to queue someone for the next Focus block. The
outgoing companion continues sleeping—and keeps ownership of the current Break
music—until Focus begins again.

## A different kind of Break

Every preset companion sleeps during Break. Assign one local MP3, M4A, or WAV
file to each color and DaburuDoro will:

- start it automatically when that character enters Break;
- play it once without looping;
- preserve playback while the widget is hidden;
- follow Timer Pause and Resume;
- use one remembered global volume; and
- fade smoothly over the final five seconds before Focus.

Music remains in the app's private local-data directory. DaburuDoro does not
upload it, stream it, or bundle it into a build.

## Smoother controls

- A centered chevron gives the progress line a large, obvious click target.
- A subtle character-level `×` hides the widget without stopping the timer.
- The five-hats control opens companion, music, and volume settings.
- Pointer hit-testing no longer gets stuck passing character clicks through to
  the desktop.

## Character activity animation

The v2 Focus frames independently redrew the whole scene, which made the lower
body and furniture jump. V3 uses standalone Focus images: frame two starts from
frame one and changes only a working hand and its operated object. Yellow moves
hands/controller, Blue changes line/bobber length, Green presses the mixer pad,
Red types at a computer, and Purple retains the approved directing state. The
companion remains anchored while visibly doing its task. Completion uses one
deliberate wave, then returns to standing.

## Known limitations

- The development build remains unsigned and unnotarized.
- Packaging targets Apple Silicon macOS.
- Custom-picture import is deferred to v5, after the v4 UI redesign.
- User-recorded notification/voice clips and the comprehensive UI redesign are
  deferred to v4.
- There is no YouTube or streaming-service integration.
