# DaburuDoro 2.0.0 — Daily Usability

Version 1 proved the core idea: an always-visible animated companion can make a
Pomodoro session feel more like body doubling. Version 2 turns that prototype
into a macOS app that can be launched, moved, hidden, recovered, configured,
and used throughout a real day.

## What is new

- **A real entry point:** launch DaburuDoro from Applications, Spotlight, or
  the Dock after building and installing the app.
- **A recoverable app:** hide the widget when it is in the way, then restore it
  from the menu-bar icon. Restart Session and Quit are available there too.
- **A movable, remembered widget:** drag anywhere on the character or control
  panel. The position persists and recovers safely when monitors change.
- **A compact focus mode:** collapse the controls to the character and a thin
  line showing how much time remains.
- **Your own rhythm:** configure whole-minute Focus and Break durations and the
  number of cycles. Every cycle includes its break, including the last one.
- **Reliable elapsed time:** the timer uses timestamps, so hiding the app or
  waking the Mac does not silently stop the session.
- **Clear transitions:** macOS notifications and an optional gentle chime mark
  the beginning of each focus or break phase and session completion.
- **An idle character state:** the companion stands and waves while waiting or
  after completion instead of continuing a work or break activity.

## What was fixed from v1

The last five-minute break now runs instead of immediately resetting after the
final focus period. The widget is draggable as one surface, expanded controls
fit without clipping, saved off-screen positions recover, and launching the app
a second time restores the existing instance.

## Under the hood

- Electron 43 with isolated renderer APIs.
- Deterministic timer, settings, and window-position modules.
- Atomic local settings persistence; no account, telemetry, or network calls.
- 14 automated Node tests.
- Apple Silicon macOS application packaging with `electron-builder`.
- Original, non-identifiable character artwork stored as local PNG frames.

## Build and install

Requires Node.js 22+ on an Apple Silicon Mac.

```bash
npm install
npm test
npm run build:mac
```

The development app is produced at `dist/mac-arm64/DaburuDoro.app`. Drag it to
Applications to install it.

## Known limitations and next versions

- This development build is not code-signed or notarized, so macOS may require
  Control-click → Open on first launch.
- Packaging currently targets Apple Silicon macOS only.
- Version 3 is reserved for five original color-themed characters, character
  selection, multi-select, and configurable activities.
- Version 4 is reserved for the larger visual-design redesign.
